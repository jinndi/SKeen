# Dashboard development

This folder is the root of the dashboard frontend project: it contains the source, npm manifest, installed dependencies, and build tools. Use Node.js 22 or later and run npm commands from this folder.

## Get started

Install the project dependencies once:

```sh
cd dashboard
npm install
```

`npm install` creates `dashboard/package-lock.json` and installs dependencies into `dashboard/node_modules/`.

Start the local development server:

```sh
npm run dev
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). The server serves the current `index.html` and automatically reloads connected browser tabs after the file is saved. Stop the server with `Ctrl+C`.

To use a different port:

```sh
PORT=5000 npm run dev
```

## Source layout

| Path | Purpose |
| --- | --- |
| `index.html` | Dashboard source, including its HTML, CSS, and JavaScript. |
| `build.js` | Minifies the standalone HTML file. |
| `dev-server.js` | Local development server; serves the source HTML as-is. |
| `package.json` | Frontend dependencies and npm scripts. |
| `package-lock.json` | Lockfile generated by `npm install` in this folder. |
| `node_modules/` | Installed frontend dependencies; generated locally. |
| `index.min.html` | Generated standalone dashboard; do not edit by hand. |

Keep the dashboard markup, styles, and script together in `index.html`. The script is a classic inline script so shared globals and inline HTML event handlers continue to work.

## Build commands

Run these commands from `dashboard/`:

| Command | Result |
| --- | --- |
| `npm run build` | Build and minify the standalone dashboard. |
| `npm run build:dashboard` | Same as `npm run build`. |
| `npm run build:api` | Build the repository-root `skeen-api` release file, embedding the dashboard. |
| `npm run build:all` | Build both the standalone dashboard and repository-root `skeen-api`. |

The dashboard build writes `index.min.html` in this folder. Generated build output and `node_modules/` are excluded from Git by the repository-root `.gitignore`; CI installs dependencies from this folder and builds the required output during deployment.

The API version is defined by the repository-root `api-version` file. The API build embeds it into the Lua file, and the static-branch workflow publishes the same file for the update mechanism. The npm package version is unrelated.
