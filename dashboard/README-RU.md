# Разработка веб-панели

Эта папка — корень frontend-проекта панели: здесь находятся исходники, npm-манифест, установленные зависимости и инструменты сборки. Требуется Node.js 22 или новее. Команды npm запускайте из этой папки.

## Быстрый старт

Один раз установите зависимости проекта:

```sh
cd dashboard
npm install
```

Команда `npm install` создаёт `dashboard/package-lock.json` и устанавливает зависимости в `dashboard/node_modules/`.

Запустите локальный сервер разработки:

```sh
npm run dev
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервер отдаёт текущий `index.html` и автоматически перезагружает открытые вкладки после сохранения файла. Чтобы остановить сервер, нажмите `Ctrl+C`.

Можно выбрать другой порт:

```sh
PORT=5000 npm run dev
```

## Структура исходников

| Путь | Назначение |
| --- | --- |
| `index.html` | Исходник панели: HTML-разметка, CSS и JavaScript. |
| `build.js` | Минифицирует автономный HTML-файл. |
| `dev-server.js` | Локальный сервер разработки; отдаёт исходный HTML без изменений. |
| `package.json` | Зависимости frontend-проекта и npm-команды. |
| `package-lock.json` | Lock-файл, создаваемый командой `npm install` в этой папке. |
| `node_modules/` | Установленные зависимости; создаются локально. |
| `index.min.html` | Собранная автономная панель; не редактируйте вручную. |

Храните разметку, стили и скрипт панели вместе в `index.html`. Скрипт остаётся обычным встроенным скриптом, чтобы сохранить общую глобальную область видимости и inline-обработчики HTML.

## Команды сборки

Запускайте команды из папки `dashboard/`:

| Команда | Результат |
| --- | --- |
| `npm run build` | Собрать и минифицировать автономную веб-панель. |
| `npm run build:dashboard` | То же, что и `npm run build`. |
| `npm run build:api` | Собрать release-файл `skeen-api` в корне репозитория со встроенной веб-панелью. |
| `npm run build:all` | Собрать автономную веб-панель и `skeen-api` в корне репозитория. |

Сборка панели создаёт `index.min.html` в этой папке. Сгенерированные файлы сборки и `node_modules/` исключены из Git через `.gitignore` в корне репозитория; CI устанавливает зависимости из этой папки и создаёт нужные артефакты во время публикации.

Версия API задаётся файлом `api-version` в корне репозитория. При сборке она встраивается в Lua-файл, а workflow статической ветки публикует этот же файл для механизма обновления. Версия npm-пакета к версии API не относится.
