### 1. Скрипт-модификатор (JS)

Для поддержки быстрых операций не обязательно писать функцию.

Перед внесением вы можете щелкнуть по узлу в интерфейсе предварительного просмотра, чтобы просмотреть структуру JSON или общую подписку на `target=JSON`.

Примеры общих операций:

1. Добавить свои префиксы к именам(тегам) узлов

```js
$server.name = 'prefix_узла-' + $server.name
```

2. Snell включает повторное использование соединений

```js
$server.reuse = true
```

3. Устанавливаем пропускную способность загрузки Hysteria 2

```js
$server.down = 200
```

4. Сменить отпеток у VLESS узлов

```
if  ( $server.type === 'vless' ) {
  $server['client-fingerprint'] = 'chrome'
}
```

и т.д., но это не всегда подходит, давайте рассмотрим пример функции operator


Вы можете щелкнуть по узлу в интерфейсе предварительного просмотра, чтобы просмотреть структуру JSON или общую подписку на `target=JSON`.

Что нужно знать о полях прокси:

1. Структура приблизительно основана на Clash.Meta (mihomo). Подробности см. в документации mihomo; например, `xudp` и `smux` можно настроить. Однако есть и некоторые личные дополнения автора, которыми я поделюсь ниже. Кстати, что касается протоколов, не поддерживаемых mihomo, вы также можете использовать форматы JSON/JSON5/YAML для ввода. Обратитесь к выводу mihomo при использовании параметра `includeUnsupportedProxy` или включении протоколов, не поддерживаемых официальной версией, например, синтаксиса ввода NaiveProxy (https://t.me/zhetengsha/4308).

2. `_no-resolve` означает, что доменное имя не должно быть разрешено.

3. После разрешения доменного имени появится дополнительное поле `_resolved`, указывающее, было ли разрешение успешным.

4. После разрешения доменного имени будут поля `_IPv4`, `_IPv6`, `_IP` (если этапов несколько, будут взяты только первые успешно полученные данные v4 или v6), `_IP4P` (если тип разрешения - IPv6 и соответствует типу IP4P, он будет автоматически преобразован), поле `_domain` и поле `_resolved_ips`, содержащее все разрешенные IP-адреса.

5. `_subName` - это имя отдельной подписки, а `_subDisplayName` - это имя отображения отдельной подписки.

6. `_collectionName` - это имя(ID) коллекции(объединенных подписок), а `_collectionDisplayName` - её отображаемое имя.

7. `tls-fingerprint` — это отпечаток TLS.

8. Для `trojan`, `tuic`, `hysteria`, `hysteria2` параметр `tls` будет установлен в значение true во время анализа (используя общую логику протоколов, подобных TLS), и будет удален при выводе.

9. В некоторых протоколах `sni` будет автоматически приведен к значению в `servername`.

10. Считываются из полей `ca-str` и `_ca` (путь к файлу бэкэнда) из узла и автоматически вычисляется отпечаток (см. https://t.me/zhetengsha/1512).

11. `test-url` - это URL-адрес для проверки задержки, а `test-timeout` - значение таймаута для проверки задержки.

12. Параметр `ports` задает параметр переключения портов, а параметр `hop-interval` - временной интервал для изменения номеров портов.

13. Параметр `ip-version` задает версию IP-адреса, используемую узлом, обеспечивая совместимость с различными провайдерами. Выполняется внутреннее преобразование. Для узлов sing-box: если совпадение не найдено, используется исходное значение. Для узлов sing-box: требуется совпадение, и поле `_dns_server` устанавливается на узле; `domain_resolver.server` будет установлено автоматически. Кроме того, узлы sing-box поддерживают установку `domain_resolver`: строка будет использоваться в качестве `server`, а объект будет объединен с `domain_resolver`.

14. Поддерживает использование `_network` для установки типа сети, например, `tcp` или `udp`. Применяется только к протоколам, имеющим поле `network` в исходном коде sing-box: `ss`, `ssr`, `socks5`, `vmess`, `vless`, `trojan`, `hysteria`, `hysteria2`, `tuic`, `snell`. Примечание: `udp: true` в стиле mihomo указывает, что узел поддерживает UDP и не будет преобразован в `network: "udp"` от sing-box; по умолчанию sing-box использует TCP+UDP. `udp: false` будет преобразован в `network: "tcp"`. `_network` является явным переопределением и имеет более высокий приоритет, чем `udp`.

15. Поддерживает `_fragment`, `_fragment_fallback_delay`, `_record_fragment`, что в `tls` устанавливает соответсвенно: `fragment`, `fragment_fallback_delay`, `record_fragment`.

16. Поддерживает `_certificate`, `_certificate_path`, `_certificate_public_key_sha256`, `_client_certificate`, `_client_certificate_path`, `_client_key`, `_client_key_path`. Устанавливает в `tls` соответсвенно: `certificate`, `certificate_path`, `certificate_public_key_sha256`, `client_certificate`, `client_certificate_path`, `client_key`, `client_key_path`

17. Поддерживает установку `curve_preferences` для `tls` с использованием полной структуры `_curve_preferences`.

18.  Snell протокол по умолчанию допускает версии 4/5/6, при этом версия 5 будет выводиться как версия 4 в соответствии с поведением Sing-box. Параметр `quic_proxy_mode` можно установить через поле `quic-proxy-mode` на узле, `_userkey` на узле будет выводиться как `userkey` Sing-box.

19. AnyTLS поддерживает установку параметра `client_metadata` через строковое поле `client-metadata` в узле.

20. Hysteria 2 поддерживает установку параметра `disable_chrome_parrot` через строковое поле `disable-chrome-parrot` в узлах.
