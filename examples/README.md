# Examples

В этой папке содержатся готовые к использованию примеры конфигураций и вспомогательные файлы для типичных вариантов настройки SKeen и sing-box.

This folder contains ready-to-use configuration examples and supporting files for common SKeen setups and sing-box.

## Навигация / Navigation

- [examples/basic/](./basic/) — базовые конфиги для TProxy, Redirect, Hybrid, Tun и маршрутизации. / Basic configs for TProxy, Redirect, Hybrid, Tun and routing.
- [examples/configs/](./configs/) — шаблоны конфигураций для стабильных, beta и legacy сборок. / Templates for stable, beta and legacy builds.
- [examples/server-client/](./server-client/) — примеры схем сервер/клиент, endpoints и оптимизации. / Server/client examples, endpoints and optimization.
- [examples/sub-store/](./sub-store/) — шаблоны и примеры работы с Sub-Store. / Templates and examples for Sub-Store.
