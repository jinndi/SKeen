# Каналы и варианты установки sing-box

При установке SKeen из меню можно выбрать официальный `sing-box`, совместимую сборку или пропустить установку и указать собственный бинарный файл. Канал `update.singbox.channel` в `skeen.json` задает источник релизов для встроенного ядра SKeen и используется командами установки/обновления и проверки обновлений. Значения в таблице соответствуют вариантам, предлагаемым установщиком SKeen.

| Значение канала | Проект / репозиторий релизов | Варианты и особенности |
| :--- | :--- | :--- |
| `official` | [SagerNet/sing-box](https://github.com/SagerNet/sing-box) | Официальная сборка. Доступны стабильные и предварительные версии (alpha/beta/rc). |
| `skb` | [jinndi/skeen-box](https://github.com/jinndi/skeen-box) | Сборка на основе официального sing-box без дополнительных build tags, предназначенная для роутеров. Доступны стабильные и предварительные версии. |
| `skb-upx` | [jinndi/skeen-box](https://github.com/jinndi/skeen-box) | То же ядро `skeen-box`, бинарник сжат UPX. Доступны стабильные и предварительные версии. |
| `pdk` | [podkop-net/podkop-engine](https://github.com/podkop-net/podkop-engine) | Экспериментальная сборка на основе стабильных релизов sing-box, базовая комплектация. Только стабильные релизы. |
| `pdk-full` | [podkop-net/podkop-engine](https://github.com/podkop-net/podkop-engine) | Экспериментальная сборка, полная комплектация. Только стабильные релизы. |
| `lx` | [Leadaxe/sing-box-lx](https://github.com/Leadaxe/sing-box-lx) | Экспериментальная сборка на основе стабильных релизов sing-box. В установщике доступны стабильный и предварительный каналы. |
| `lx-upx` | [Leadaxe/sing-box-lx](https://github.com/Leadaxe/sing-box-lx) | То же ядро `sing-box-lx`, UPX-вариант для поддерживаемых архитектур. В установщике доступны стабильный и предварительный каналы. |
| — | Собственный бинарный файл | Можно пропустить установку встроенного ядра и настроить сторонний бинарный файл через `singbox.external` в [`skeen.json`](CONFIGURATION-RU.md). Его установка и обновление выполняются пользователем; автоматический канал SKeen для него не применяется. |

Предварительные версии управляются отдельно настройкой `update.singbox.beta`. Для `podkop-engine` доступны только стабильные релизы. Поддержка UPX и конкретных архитектур зависит от выбранной сборки и модели роутера; `lx-upx` не предоставляет UPX-пакет для MIPS.
